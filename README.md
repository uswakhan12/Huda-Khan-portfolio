# Portfolio (Vite + React)

This scaffold renders a portfolio site / CV using React + Vite. Replace the placeholder data in `src/data.js` with your CV content.

Run locally:

```
npm install
npm run dev
```

Files to edit:
- [src/data.js](src/data.js#L1) — replace name, summary, experience, education, courses, skills, contact.
- [src/App.jsx](src/App.jsx#L1) — main layout (`App`).

Build:

```
npm run build
npm run preview
```
